# fundamentos-html-css

Manual práctico para empezar desde cero con HTML y CSS.

## Objetivo

Este repositorio está pensado para principiantes nivel 0: personas que nunca han maquetado una página web.

## Estructura versionada

- `manuales/v1-nivel-0-html-css.md`: primera versión del manual base para iniciar.

La idea es seguir publicando mejoras por versión (`v2`, `v3`, etc.) sin perder el historial de aprendizaje.
